# SuperBot Ai Assistant

An AI-powered assistant.

## Features

- Create new chats
- Edit existing chats
- Rename or delete chat sessions
- Chats are stored locally with **IndexedDB**
- Search across all chat history
- Streaming responses for real-time answers
- Simple authentication
- Dark mode & light mode support with **next-themes**
- Using React-Virtuoso for optimized rendering of long chat message lists

## Tech Stack

- React.js
- TailwindCSS
- shadcn/ui
- next-themes
- IndexedDB
